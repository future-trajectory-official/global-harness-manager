# /refactoring — リファクタリング・ワークフロー

本コマンドはワークフロー `refactoring` をメインセッションで実行するための入口です。
**手順の単一の正は以下のワークフロー定義ファイルです。全文を読み、記載どおりにフェーズ進行すること。**

@.agents/workflows/refactoring.md

## 実行順序と状態遷移（呼出側の概要）

| フェーズ | 実行スキル | 実行後の状態（業務用語） |
| --- | --- | --- |
| 1-1. 事前メトリクスの測定 | —（直操作） | 改善前メトリクスが記録されユーザーと共有済み |
| 1-2. テストの健全性確認（中止判断） | —（直操作） | テスト存在とGreen確認、不適なら中止を報告済み |
| 2-1. 実行環境のセットアップ | develop-environment-setup | 独立した作業環境（サンドボックス）が準備済み |
| 2-2. 作業ブランチの作成 | initialize-branch | 目的承認の上、作業ブランチが作成済み |
| 3-1. 安全な変更の適用とWIP保存 | refactoring-loop / hybrid-triage-commit | 挙動を変えない適用完了、WIPセーブポイント作成済み |
| 4-1. 厳格な回帰テスト | —（直操作） | 全テストGreenで変更後の期待動作が証明済み |
| 4-2. 事後メトリクスの測定と改善報告 | —（直操作） | 前後メトリクス比較による改善根拠が提示済み |
| 5-1. コミット履歴のトリアージと再構築 | hybrid-triage-commit | WIP履歴がアトミックコミットへ再構築済み |
| 5-2. PR作成と報告 | create-pull-request | メトリクス改善要約付きPRが作成済み |
| 5-3. マージとクリーンアップ | merge-branch | 承認後PRマージされ環境が同期済み |

## 遵守事項

- ワークフロー内の `<!-- STOP -->` と停止指示は Opencode の機能ではなく AI への指示表記である。到達点で必ず報告し、PO の明示的な指示があるまで次のフェーズを先読みしない。
- コマンドは呼出側の事情（実行順序・状態遷移）のみを表現する。各実行スキルの内部操作（手順・コマンド・JSON形式）には踏み込まない。
- 並行実行を要する個所がある場合、コマンド自身はサブエージェントを起動せず、該当スキル側がサブエージェントの作成・実行を明示的に行う方針に従う（本ワークフローに並行実行個所なし；将来のスキル変更時もこの方針を維持する）。
