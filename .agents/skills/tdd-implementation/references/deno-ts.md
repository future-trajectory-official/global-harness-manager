# Deno/TypeScript TDD リファレンス

Deno 環境で TDD を実行する際の具体的なコマンドとベストプラクティスです。

## 推奨コマンド

### 1. テスト実行 (RED/GREEN確認)
```bash
deno test -A --parallel
```
- `-A`: 必要な権限を許可（必要に応じて絞り込む）。
- `--parallel`: 高速化（副作用がない場合）。

### 2. 品質検証 (DoD)
```bash
# 構文および型の整合性チェック
deno check **/*.ts

# リンター (公式ルール)
deno lint

# フォーマットの整合性 (修正せずにチェックのみ)
deno fmt --check
```

## 実装のポイント

- **テストコードの配置**: 原則として実装ファイルと同じディレクトリに `filename_test.ts` として配置します。
- **標準ライブラリの活用**: `@std/assert` を使用してください。
- **モック**: 外部通信やファイル操作が伴う場合は、`Deno.Command` のモックや一時ディレクトリを活用してください。
