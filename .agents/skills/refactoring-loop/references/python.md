# Python リファクタリングリファレンス

Python 環境でのコード品質測定とリファクタリングのポイントです。

## 計測・分析ツール

### 1. 複雑度・保守性指数の計測
```bash
# サイクロマチック複雑度の計測
radon cc <path> -s

# 保守性指数 (MI) の計測
radon mi <path>
```

### 2. 静的解析
```bash
ruff check .
```

## リファクタリングのポイント

- **関数の抽出**: 複雑度が高い関数を小さな部品に分割します。
- **型ヒントの追加**: 振る舞いを変えない範囲で `typing` を導入し、保守性を高めます。
- **重複削除**: `flake8-blind-except` や `ruff` の各種プラグインで重複を検知します。
