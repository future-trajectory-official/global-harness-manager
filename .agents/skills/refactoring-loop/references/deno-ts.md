# Deno/TypeScript リファクタリングリファレンス

Deno 環境でのコード品質測定とリファクタリングのポイントです。

## 計測・分析ツール

### 1. 静的解析
```bash
deno lint
```
- `cyclomatic-complexity` などの警告が出ていないか確認してください。

### 2. コード構造の可視化
```bash
deno doc --json <file_path>
```
- 依存関係やエクスポートされているインターフェースの肥大化を確認できます。

### 3. テストカバレッジ
```bash
deno test --coverage=cov_profile
deno coverage cov_profile
```
- リファクタリング対象のコードがテストで保護されているか確認してください。

## リファクタリングのポイント

- **型安全性の維持**: `deno check` を頻繁に実行し、型定義が壊れていないか確認します。
- **ファイル分割**: 1ファイルが 300〜500 行を超え始めたら、責任の分離を検討してください。
- **デッドコード削除**: 未使用のインポートや変数は `deno lint` で検出し、削除します。
