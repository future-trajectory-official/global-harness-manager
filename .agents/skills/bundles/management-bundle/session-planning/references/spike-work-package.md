# スパイクWP (Spike Work Package) リファレンス

## 概要

技術的不確実性が高いWork Packageについて、本実装の前に実施する事前調査用のWork Package。

## 定義

- **スパイクWP** (`WP_N` 表記): 技術的検証・調査・プロトタイピングに特化した一時的なWP
- **成果物**: 調査レポート（採用技術の決定、アーキテクチャの確定、リスクの特定等）
- **サイズ**: 原則 XS（1セッションで完了可能な範囲）

## 命名規則

| 表記    | 意味                                                 |
| ------- | ---------------------------------------------------- |
| `WP_N`  | スパイクWP（Nは任意の番号）                          |
| `WP_M'` | スパイク完了後の正式化された本実装WP（プライム表記） |

## 運用ルール

1. **発行**: `identify-work-package` または `session-planning` 時に、PO判断で分離
2. **調査範囲の明示**: ACに調査範囲・検証項目・合格基準を明記
3. **移行条件**: スパイクWP完了をもって `WP_M'` の `session-planning` を開始可能
4. **参照リンク**: スパイクWPの調査レポートは `WP_M'` のバックログに `- **参照**: [link]` 形式で明記

## 乖離シグナル

`WP_M'` の計画前見積と完了時実績の乖離が2倍以上の場合、スパイクが不十分だった可能性を示すシグナル。
