# kpt-session-reflection

セッションの質を内省し、AI と人間が共進化するための気づきを得るためのスキルです。

## 手順

1. **セッションログの解析**
   - 本セッションの全ログを読み込み、[reflection-guide.md](references/reflection-guide.md)
     に基づいて KPT と AI フィードバックを生成してください。

2. **内省の出力**
   - 生成された内省を提示し、次回の協働品質向上に向けた対話を行ってください。
