# ベロシティ集計アルゴリズム詳細

## ウェイトマッピング

| Tシャツサイズ | ウェイト |
| :------------ | :------: |
| XS            |    1     |
| S             |    2     |
| M             |    3     |
| L             |    5     |
| XL            |    8     |

## 集計項目

| 項目             | 算出方法                                                                              |
| ---------------- | ------------------------------------------------------------------------------------- |
| 開発PBI数        | 指定スプリントに属するアーカイブPBIの総数                                             |
| 合計ウェイト     | 各PBIの見積サイズをウェイトマッピングで変換し総和                                     |
| 実感サイズ一致率 | 見積サイズ = 実感サイズ のPBI数 ÷ 全PBI数（空の場合は 1.0）                           |
| 乖離要約         | 乖離PBIごとに「PBI名が 見積→実感 に乖離」フォーマットで列挙。全一致の場合は「全一致」 |

## テーブル行フォーマット

```markdown
| Sprint N | PBI数 | 合計ウェイト | 一致率表示 | 乖離要約 |
```

- 一致率表示: 1.0 → "全一致", 0.0 → "全乖離", それ以外 → "N%一致"

## 振る舞い定義

### 正常系

- 該当スプリントの全PBIがアーカイブにある場合、正しく集計してテーブルに追記する

### エッジケース

- **空のスプリント**: 該当PBIが0件の場合、空行を追記する（エラーにしない）
- **全乖離**: 全PBIで見積≠実感の場合、一致率0.0、"全乖離"表示
- **部分乖離**: 一部のPBIのみ乖離している場合、乖離PBIを個別に列挙
