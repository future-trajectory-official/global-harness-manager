# summarize-session-outcomes

セッションの最後に実行し、どのような AC をクリアし、どのような成果物が生成されたかを PO
に報告するためのスキルです。

## 手順

1. **成果の要約実行**
   - ログとファイルシステムを確認し、[summary-guide.md](/.agents/skills/bundles/management-bundle/summarize-session-outcomes/references/summary-guide.md)
     に基づいて成果要約を出力してください。

2. **PO への報告**
   - 生成された要約を提示し、現在の進捗状況を同期してください。
