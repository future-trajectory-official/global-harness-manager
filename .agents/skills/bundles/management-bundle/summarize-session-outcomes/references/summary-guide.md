# Session Outcome Summary Guide

セッションの成果を要約するためのガイドラインです。

## 要約のステップ

1. **計画の参照**: `implementation_plan.md` を読み込み、当初の目標を確認します。
2. **実績の集計**:
   ログおよびファイルシステムから、実際に完了したタスクと生成/修正されたファイルを特定します。
3. **乖離の分析**: 計画通りに進まなかった点や、計画外で発生した作業を抽出します。

## 出力形式

以下の形式で報告を行います。

```markdown
### [Session Outcome Summary]

#### 1. AC（受け入れ基準）の達成状況

- [x] [計画時の AC 1] - [達成内容のエビデンスや確認結果]
- [ ] [未達の AC 2] - [未達の理由や次回の対応]

#### 2. 生成・修正された成果物

- [ファイル名またはリンク](URL) - [変更内容の簡潔な説明]

#### 3. 計画からの変更点

- [計画外で発生した作業や、アプローチの変更があれば記述]
```
