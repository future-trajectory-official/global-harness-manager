# Display Principles

このスキルの出力は PO がセッションの**価値判断基準**を整えるために使われる。
以下の観点を満たすように表示を構成すること。

## 伝えるべき情報

| データ           | なぜ必要か                                                                                                                             |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Vision Statement | プロジェクトの存在意義。これからの判断の「Why」を示す。PO が今すぐ確認し、セッション中の判断軸として機能するように                     |
| 保有ロール一覧   | 現在チームが行使可能な専門能力。何にでも対応できるわけではないことを PO に認識させ、スコープ管理に役立てる                             |
| 主要スキル一覧   | 自動化された手順・ツール群の棚卸し。「今回の作業は単発処理か、スキル化すべき繰返し処理か」という気付きを与え、スキル化の判断材料にする |

## 表示上の注意

- PO は忙しい。冗長な装飾や不要な説明は省き、情報そのものが伝わる表示を心がける
- 「何ができるか」より「今セッションでこれを判断基準にできる」という文脈を意識する
- 生JSON のまま投げない。AI が咀嚼して初めて価値になる
