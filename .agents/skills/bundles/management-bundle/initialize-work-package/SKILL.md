# initialize-work-package

Work
Packageを開始する前に、開発環境の現状と利用可能なルール、そして目的をユーザーと同期するための必須ステップです。

## 手順

// turbo-all

1. **基本原則と環境の確認**
   - `find .agents -maxdepth 4` を実行し、利用可能なルール、スキル、ワークフローの構造を把握する。
   - **`.agents/rules/*.md`
     で定義された各役割（Role）の制約を再確認し、本セッションを通して厳格に遵守することを誓約する。**

2. **プロセスの復唱と制約の確認**
   - 実行しようとしているワークフローの名前とその全ステップを提示する。
   - その際、**各ステップで呼び出す役割名と、その役割が守るべき主要な制約をあわせて提示し**、手順と行動指針に漏れがないか確認する。

3. **バックログの確認とスコープの極小化**
   - プロダクトバックログを読み込み、現在の状況をユーザーに報告する。
   - **「このセッションで実行するWork Packageをただ１つだけ」**明示的に宣言し、スコープを絞る。

## ⚠️ 注意事項

- 本スキルは「作業開始の宣言」です。これをスキップして直接実装に入ると、コンテキストの不一致による手戻りが発生するリスクが高まります。
- 複数のWork Packageを並行して宣言しないでください。
