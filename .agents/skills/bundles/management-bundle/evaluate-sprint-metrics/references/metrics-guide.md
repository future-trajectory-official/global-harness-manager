# Sprint Metrics Evaluation Guide

スプリント全体の品質とプロセス規律を定量評価するためのガイドラインです。

## 評価指標の定義

### 1. Goal Achievement Rate (ゴール達成率)

- **定義**: 計画されたPBIおよびスプリントゴールに対する完了の割合。
- **採点基準**:
  - 1: スプリントゴールが未達で、PBIの半分以上が未完了のまま残った。
  - 3: スプリントゴールは一部達成され、主要なPBIが完了した。
  - 5: すべてのPBIを完遂し、スプリントゴールを完璧に達成した。

### 2. Velocity & Estimation Accuracy (規模消化力と見積もり精度)

- **定義**: 完了したPBIの「見積時Tシャツサイズ」のウェイト（具体的なポイント換算基準は
  [backlog-guidelines.md の「2.2. PBI の見積り基準 (T-Shirt Size)」](/.agents/management/backlog-guidelines.md)
  を参照）の集計値による独自ベロシティと、それに要した実際のセッション数（労力）のバランス。
- **採点基準**:
  - 1:
    完了したTシャツサイズのウェイトに対して、セッション数・手戻りが異常に多い（見積もりに対して極めて重かった）、またはほとんど消化できなかった。
  - 3:
    Tシャツサイズと実際の労力に多少のブレ（思ったより大きかった/小さかった等）はあったが、概ね妥当なペースで消化された。
  - 5: 見積もられたTシャツサイズ通りの労力で、事前の予測通りにスムーズにPBIが消化された。

### 3. Quality Integrity (品質健全性)

- **定義**:
  スプリントを通じてマージされたコード全体の品質（リリースビルド・CI/CDの健全性、回帰テストの成功、および全体のテストカバレッジ維持）。
- **採点基準**:
  - 1: リファクタリングによる他機能の破損や、ビルドエラーがスプリント中に多発した。
  - 3: 軽微なバグの修正はあったが、最終的にリリース品質およびテスト網羅性が維持された。
  - 5:
    スプリント最終成果物の全自動テストが完全に成功し、手戻りや回帰バグの発生なくクリーンな状態が保たれた。

### 4. Collaboration & Process Discipline (協働品質とプロセス規律)

- **定義**: [metrics.jsonl](/.agents/management/metrics.jsonl)
  に記録されたセッションメトリクス（Intent,
  Constraint等のスコア推移）の健全性と、スプリントを通じた運用規律（セレモニーの確実な遂行、アトミックコミットの徹底）の総合評価。
- **採点基準**:
  - 1:
    セッションメトリクスが慢性的に低く（やり直しが多発）、セレモニーのスキップ等でプロセスの規律が乱れた。
  - 3:
    メトリクスに多少の波はあったが、原則としてすべてのスプリント境界ルールと協働プロトコルが守られた。
  - 5:
    すべてのセッションが高いメトリクスを叩き出し、あらゆるセレモニーと一時クリーンアップが完璧に実行された。

## 出力形式

```markdown
### [Sprint Metrics Summary]

| 評価指標                       | スコア | 評価の根拠                        |
| :----------------------------- | :----: | :-------------------------------- |
| **Goal Achievement Rate**      | [1-5]  | [具体的な達成内容]                |
| **Velocity & Estimation**      | [1-5]  | [Tシャツサイズと実労力の乖離分析] |
| **Quality Integrity**          | [1-5]  | [テスト網羅度とバグ発生状況]      |
| **Collaboration & Discipline** | [1-5]  | [metrics.jsonlの推移と規律遵守度] |
```
