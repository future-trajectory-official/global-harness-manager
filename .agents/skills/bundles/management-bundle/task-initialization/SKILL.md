# task-initialization

タスクを開始する前に、開発環境の現状と利用可能なルール、そして目的をユーザーと同期するための必須ステップです。

## 手順

// turbo-all

1. **エージェント環境の確認**
   - `find .agents -maxdepth 2` を実行し、利用可能なルール、スキル、ワークフローを軽く確認する。

2. **プロセスの復唱**
   - 実行しようとしているワークフローの名前とその全ステップをチャットで提示し、手順に漏れがないか確認する。

3. **バックログの確認とスコープの極小化**
   - プロダクトバックログを読み込み、現在の状況をユーザーに報告する。
   - **「このセッションで実行するタスクをただ１つだけ」**明示的に宣言し、スコープを絞る。

4. **Git ステータスの確認**
   - `git status` を実行し、現在のブランチと差分を確認して報告する。

※ ユーザーから「作業開始のGO」を得るまで、実際のファイル操作には移行しないこと。
