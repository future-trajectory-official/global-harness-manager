# AC-Checkpoint-Implementation

本スキルは、実装フェーズにおいて計画（implementation_plan.md）に列挙されたACの**1つを入力として受け取り**、そのACを満たすための検証手段の作成
→ 実装 → 検証完了までの1サイクルを実行する。
実装フェーズの中でACの数だけ繰り返し呼ばれることを想定しており、「先にゴール（検証手段）を設定し、それを達成する」という自己目的達成型の能力を提供する。

## 前提条件

- 実装計画（implementation_plan.md）に受入基準（AC）が列挙されていること
- プロジェクト内にテストランナー（`deno test` 等）がセットアップされていること

## 実行手順

### Step 1: 入力の受付

- 実装計画（implementation_plan.md）から**1つのAC**を選択し、その内容を確認する。
- 当該ACに対応する実装対象（ファイル・関数・振る舞い）を特定する。

### Step 2: 検証手段の作成

- 選択したACを満たすことを証明するテストコードまたは検証スクリプトを**先に**作成する。
- テストはまだパスしないことを確認する（RED相当）。
- 言語別のテスト実装パターンは `references/` を参照すること。

### Step 3: 実装

- Step 2で作成した検証手段がパスする**最小限のロジック**を実装する。

### Step 4: 検証

- 検証手段が実際にパスすることを確認する（GREEN相当）。
- テスト失敗時はStep 3に戻り修正を繰り返す。

### Step 5: 完了報告

- 当該ACが完了したことを明確に報告する。

## 関連スキルとの関係

本スキルは以下のスキルと**置き換え・補完関係**にある：

| スキル                       | 関係                 | 説明                                                                                                                                    |
| ---------------------------- | -------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `define-acceptance-criteria` | 補完（上流）         | ACの**定義**フェーズを担当。本スキルは定義されたACの**実装**フェーズを担当。両者は直列に連携する。                                      |
| `tdd-implementation`（旧）   | 置き換え（削除済み） | 本スキルがTDDの実践を内在化するため、`tdd-implementation` は本スキル作成と同時に廃止された。言語別リファレンスは `references/` に継承。 |

## 注意事項

- **単一AC単位で呼び出すこと**:
  複数のACをまとめて処理しない。ACの数だけ本スキルを繰り返し呼び出すこと。
- **タスクステータス同期は行わない**:
  task.mdのチェックボックス更新は本スキルの責務外。外側のワークフローが管理する。
- **WIPコミットは行わない**: Gitコミットは本スキルの責務外。外側のワークフローが管理する。
- **本スキルをサブエージェント（Task tool）に委譲して呼び出すことを推奨する**:
  親エージェントのコンテキストを維持したまま、各ACサイクルを独立して実行できる。
