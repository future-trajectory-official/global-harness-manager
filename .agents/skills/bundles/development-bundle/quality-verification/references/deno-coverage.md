# Deno カバレッジ測定リファレンス

## 測定方法

```bash
# カバレッジ測定付きテスト
deno task test:cov
```

## カバレッジ情報の読み方

`deno coverage` の出力例:

```
foobar.ts     ________________________________________________________________ 100.00%
bar.ts        _________________________________________                        73.68%
baz.ts        ________________________________________________________________ 100.00%
```

各行のフォーマット: `[ファイルパス] [進捗バー] [カバレッジ率]`

- 低カバレッジのファイルがある場合、未カバレッジ行を特定しテストを追加する。
- **目標水準**: 全体カバレッジ 80% 以上を推奨。

## ⚠️ 注意事項

- カバレッジ出力先のディレクトリは `deno.json` のタスク定義に従う。
- カバレッジデータのクリーンアップは本スキルの責務外。
